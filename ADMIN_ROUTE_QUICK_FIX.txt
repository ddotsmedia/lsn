🎯 ADMIN ROUTE 404 ERROR - QUICK FIX GUIDE
═══════════════════════════════════════════════════════════════════════════════

PROBLEM:
  /admin route returns 404 instead of showing Admin Panel

ROOT CAUSE:
  Stale Next.js build cache (.next/ directory) on VPS

SOLUTION:
  Clear cache and rebuild Docker image

═══════════════════════════════════════════════════════════════════════════════
⚡ QUICK FIX (Copy & Paste on VPS)
═══════════════════════════════════════════════════════════════════════════════

ssh admin@lsn.ae
cd /app/lsn
git pull origin main
rm -rf apps/frontend/.next
docker-compose down -v
docker image prune -a -f
pnpm install
docker-compose build --no-cache
docker-compose up -d
sleep 30
curl https://lsn.ae/admin
